### **API**

An Application Programming Interface (API) allows different software systems to communicate and share data or functionality.

### **SDK**

A Software Development Kit (SDK) provides tools, libraries, and documentation to help developers build applications for a specific platform.

### **Web APIs**

Web APIs enable communication between applications over the internet.

### **Library APIs**

Library APIs are prewritten functions or classes within a library, enabling developers to reuse code and add specific features.

### **Prompting and Completion**

In AI, prompting involves giving an input query to the model, while completion is the model's generated response based on the input.
